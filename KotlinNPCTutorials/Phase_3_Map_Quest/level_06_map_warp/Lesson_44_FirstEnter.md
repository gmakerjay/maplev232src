# 🎓 Level 44: ยินดีต้อนรับสู่แมพ (First Enter Field)

เคยไหม? เข้าแมพมาครั้งแรกแล้วมี NPC เด้งคุยเอง หรือมี Cutscene?
นั่นคือพลังของ **FirstEnterField** Script

## 📜 ภารกิจที่ 46: สคริปต์ต้อนรับ
ไฟล์พวกนี้ไม่ได้อยู่ในคุยกับ NPC แต่อยู่ในโฟลเดอร์ `scripts/field`
ชื่อไฟล์ต้องตรงกับ Map ID (เช่น `100000000.kts`)

### **Code ตัวอย่าง (scripts/field/100000000.kts)**
```kotlin
// สคริปต์นี้จะรัน "ครั้งแรก" ที่ตัวละครเข้าแมพนี้ (หลังจาก Login หรือย้าย Channel จะรีเซ็ตสถานะนี้มั้ง แล้วแต่ Server)
// ปกติใช้สำหรับ Tutorial

sm.sendNext("ยินดีต้อนรับสู่หมู่บ้านเห็ด!")
sm.sendNext("กดลูกศรเพื่อเดิน และ Alt เพื่อกระโดดนะ")
sm.sendSayOkay("ขอให้โชคดี!")

// พอจบปุ๊บ ตัวละครถึงจะขยับได้
```

---

## 🧐 **การทำงาน**
มันจะ Block User Input จนกว่าคุยจบ
ถ้าไม่อยากให้ Block (อยากให้แค่ขึ้นข้อความเตือนมุมจอ) ต้องใช้ `sm.chatScript` หรือคำสั่ง Notice อื่นๆ

---

## ✍️ **แบบฝึกหัด (ลองทำดู)**
สร้างไฟล์ `scripts/field/999999999.kts` (สมมติแมพเทส)
ให้เด้งข้อความ "ระวังตัวด้วย!"

(เฉลย: ก็เขียน `sm.sendSayOkay("ระวังตัวด้วย!")` ใส่ไฟล์ชื่อนั้น จบ!)
