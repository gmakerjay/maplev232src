# 🎓 Level 1: Hello Kotlin NPC!

ยินดีต้อนรับสู่โลกของ Kotlin Scripting! ลืม Python แบบเก่าๆ ไปซะ เพราะ Kotlin คือความเท่แบบ Type-Safe ที่จะทำให้คุณไม่อยากกลับไปเขียนภาษาอื่นอีกเลย!

## 📜 ภารกิจที่ 1: NPC ตัวแรก (The First NPC)
เรามาดูโครงสร้างพื้นฐานกันก่อน ใน Python คุณอาจจะชินกับ `sm.sendSay("Text")` ใน Kotlin ก็เหมือนกันเป๊ะ! แต่ดีกว่าตรงที่เราไม่ต้องห่วงเรื่อง Indentation (ย่อหน้า) บ้าบอคอแตก

### **Code ตัวอย่าง (Example.kts)**
```kotlin
// NPC: 9010000 - Maple Administrator
// นี่คือ Comment ใน Kotlin ใช้ // เหมือน C++ หรือ Java

// 1. ทักทาย
sm.sendSay("สวัสดี! นี่คือ NPC ตัวแรกที่เขียนด้วย Kotlin")

// 2. คุยต่อ (Next)
sm.sendNext("ข้อดีของ Kotlin คือมัน Modern มากๆ")

// 3. ย้อนความหลัง (Prev)
sm.sendPrev("เมื่อกี๊ฉันพูดว่าอะไรนะ?")

// 4. จบการสนทนา (Okay)
sm.sendSayOkay("เอาล่ะ เจอกันใหม่นะจ๊ะ!")
```

## 🧐 **ไวยากรณ์น่ารู้ (Grammar Breakdown)**

| คำสั่ง (Syntax) | ความหมาย | อารมณ์ |
| :--- | :--- | :--- |
| `sm.` | ย่อมาจาก **Script Manager** เป็นพระเจ้าผู้ควบคุมทุกอย่างในสคริปต์นี้ | "เฮ้ย ระบบ!" |
| `sendSay("...")` | กล่องข้อความธรรมดา มีปุ่ม Next | พูดเฉยๆ |
| `sendNext("...")` | กล่องข้อความที่มีปุ่ม Next/Prev | เล่าเรื่องต่อ |
| `sendPrev("...")` | กล่องข้อความที่มีปุ่ม Prev/Next | ย้อนกลับไปดู |
| `sendSayOkay("...")` | กล่องข้อความที่มีปุ่ม Ok (จบ) | สรุปจบ ปิดเคส |

> **💡 Pro Tip:** ข้อความใน "..." ต้องเป็น String เสมอ ห้ามลืมเครื่องหมายคำพูดเด็ดขาด!

## 🔍 **เจาะลึก: ทำไมต้อง Kotlin? (Why Kotlin?)**
ใน Python คุณอาจจะเจอ Error งงๆ เวลาลืมย่อหน้า หรือพิมพ์ตัวแปรผิด
แต่ใน Kotlin...
1.  **Semicolon (;)** ใส่ก็ได้ ไม่ใส่ก็ได้ (เท่ป่ะล่ะ)
2.  **Type Safety** ถ้าคุณสั่ง `sm.sendSay(123)` (ใส่ตัวเลข) มันจะเตือนตั้งแต่รันเลยว่า "เฮ้ย ผิดเว้ย!" (ต้องแปลงเป็น String ก่อน)
