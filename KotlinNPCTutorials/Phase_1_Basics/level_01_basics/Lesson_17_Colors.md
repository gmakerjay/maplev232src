# 🎓 Level 17: ศิลปินระบายสี (Text Formatting)

NPC ที่พูดแต่ตัวหนังสือสีดำมันน่าเบื่อ! มาใส่สี ใส่ตัวหนา ใส่รูปไอเทมกันเถอะ

## 📜 ภารกิจที่ 21: รหัสลับแดงเขียวฟ้า
MapleStory มี Tag พิเศษที่ใช้แทรกใน String ได้เลย

| Tag | ผลลัพธ์ | Tag | ผลลัพธ์ |
| :--- | :--- | :--- | :--- |
| `#b` | **สีน้ำเงิน (Blue)** | `#r` | **สีแดง (Red)** |
| `#k` | **สีดำ (Black - Reset)** | `#g` | **สีเขียว (Green)** |
| `#d` | **สีม่วง (Purple)** | `#e` | **ตัวหนา (Bold)** |
| `#n` | **ตัวปกติ (Normal - Unbold)** | `#h #` | **ชื่อเรา (Your Name)** |
| `#i[ID]#` | **รูปไอเทม** | `#z[ID]#` | **ชื่อไอเทม** |
| `#m[ID]#` | **ชื่อแมพ** | `#v[ID]#` | **รูปสกิล** |

### **Code ตัวอย่าง (Color.kts)**
```kotlin
val swordId = 1302000 // ดาบมือเดียว
val msg = """
    สวัสดี #h #!
    วันนี้ฉันมี #b#z$swordId##k (#i$swordId#) มาขาย
    ราคาเพียง #r500,000#k Mesos เท่านั้น!
    #eสนใจไหม?#n
""".trimIndent()

sm.sendNext(msg)
```
> **สำคัญ:** อย่าลืมปิดด้วย `#k` (กลับเป็นสีดำ) ไม่งั้นสีมันจะไหลไปทั้งประโยค!

---

## 🧐 **การใช้ `\r\n` (ขึ้นบรรทัดใหม่)**
บางทีข้อความยาวเกินไป ต้องตัดบรรทัดเอง
*   `\r\n` = New Line
*   ใน Kotlin String Template (3 ฟันหนู) `"""..."""` กด Enter ได้เลย ไม่ต้องใช้ `\r\n`

## ✍️ **แบบฝึกหัดท้าประลอง (Challenge)**

**โจทย์:** ป้ายประกาศจับ (Wanted Poster)
1.  แสดงชื่อเรา (`#h #`) แบบ **ตัวหนา**
2.  แสดงข้อความ "WANTED DEAD OR ALIVE" เป็น **สีแดง**
3.  แสดงรางวัลนำจับ "1,000,000,000 Mesos" เป็น **สีน้ำเงิน**
4.  ใส่ icon เหรียญเมโซข้างหลังรางวัล (`#i4031138#` - ลองหาไอดีเหรียญดู)

**เฉลย:**

<summary>คลิกเพื่อดูเฉลย</summary>

```kotlin
// 4031138 = Old Meso Coin (Example ID)
val msg = """
    #e#h ##n
    #rWANTED DEAD OR ALIVE#k
    Reward: #b1,000,000,000#k #i4031138#
""".trimIndent()

sm.sendSayOkay(msg)
```
