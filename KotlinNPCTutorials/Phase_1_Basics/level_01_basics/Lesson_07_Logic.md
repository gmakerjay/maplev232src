# 🎓 Level 7: ตรรกะพารวย (Logical Operators)

โลกนี้ไม่ได้มีแค่จริงกับเท็จ แต่มันมี "และ", "หรือ", "ไม่" ด้วย!

## 📜 ภารกิจที่ 11: เงื่อนไขซ้อนเงื่อน
*   `&&` (AND): ต้องจริง **ทั้งคู่** ถึงจะผ่าน
*   `||` (OR): จริง **แค่อันใดอันหนึ่ง** ก็ผ่าน
*   `!` (NOT): กลับดำเป็นขาว (จริง -> เท็จ, เท็จ -> จริง)

### **Code ตัวอย่าง (Logic.kts)**
```kotlin
val level = chr.level
val money = sm.getMesos() // สมมติว่ามีฟังก์ชันนี้ (เดี๋ยวเรียนละเอียดในบทถัดไป)

// โจทย์: ต้องเลเวล 10+ และมีเงิน 1000+ ถึงจะผ่าน
if (level >= 10 && money >= 1000) {
    sm.sendSayOkay("ผ่านเกณฑ์! เชิญเข้าได้")
} else {
    sm.sendSayOkay("คุณสมบัติไม่ครบ! กลับไปฟาร์มมาก่อน")
}

// โจทย์: เป็น GM หรือ เลเวล 200+ ก็ได้
if (chr.isGm() || level >= 200) {
    sm.sendSayOkay("ยินดีต้อนรับท่านเทพ (หรือท่าน GM)")
}
```

## 🧐 **ไวยากรณ์น่ารู้ (Boolean Logic)**

### การใช้ `!` (Not)
มีประโยชน์มากเวลาเช็ค "ของขาด" หรือ "ยังทำไม่เสร็จ"

```kotlin
val isFinished = false

if (!isFinished) { // อ่านว่า "if not isFinished" (ถ้ายังไม่เสร็จ)
    sm.sendNext("งานยังไม่เสร็จนะ รีบไปทำซะ!")
}
```
