# 🎓 Level 4: ตัวเลขมหัศจรรย์ (Selections with Numbers)

การใส่ตัวเลขเป็นหัวใจสำคัญของการซื้อขาย แลกเปลี่ยน หรือทายปริศนา! วันนี้เราจะมาเรียนรู้วิธีให้ผู้เล่นกรอกตัวเลขกันครับ

## 📜 ภารกิจที่ 6: ขอเบอร์หน่อย (Get Number)
คำสั่ง `sm.sendAskNumber` ใช้สำหรับให้ผู้เล่นพิมพ์ตัวเลขลงไป
*   **Argument 1**: ข้อความคำถาม
*   **Argument 2**: ค่าเริ่มต้น (Default)
*   **Argument 3**: ค่าน้อยสุด (Min)
*   **Argument 4**: ค่ามากสุด (Max)

### **Code ตัวอย่าง (AskNumber.kts)**
```kotlin
// ถามอายุ: เริ่มต้นที่ 20, ต่ำสุด 1, สูงสุด 100
val age = sm.sendAskNumber("นายอายุเท่าไหร่?", 20, 1, 100)

if (age < 18) {
    sm.sendSayOkay("เด็กน้อย! กลับบ้านไปกินนมแม่ไป๊!")
} else if (age > 60) {
    sm.sendSayOkay("ระวังปวดหลังนะปู่")
} else {
    sm.sendSayOkay("กำลังโตเลยนะเนี่ย")
}
```

## 🧐 **ไวยากรณ์น่ารู้ (Grammar Breakdown)**

### 1. **Comparison Operators (ตัวเปรียบเทียบ)**
*   `<` น้อยกว่า
*   `>` มากกว่า
*   `<=` น้อยกว่าหรือเท่ากับ
*   `>=` มากกว่าหรือเท่ากับ
*   `==` เท่ากัน (อย่าลืมใช้ 2 อันนะ!)
*   `!=` ไม่เท่ากัน

### 2. **Else If (ถ้าไม่ใช่อันบน แล้วเป็นอันนี้ไหม?)**
```kotlin
if (เงื่อนไข 1) {
    // ทำเมื่อ 1 จริง
} else if (เงื่อนไข 2) {
    // ทำเมื่อ 1 ไม่จริง แต่ 2 จริง
} else {
    // ทำเมื่อทุกอันไม่จริงเลย
}
```

## 📜 ภารกิจที่ 7: เกมทายตัวเลข (Number Guessing Game)
ลองเอาความรู้เรื่อง Loop (ที่เราจะเรียนลึกๆ ทีหลัง) มาผสมกันหน่อย

### **Code ตัวอย่าง (GuessGame.kts)**
```kotlin
val secretNumber = 42
var guess = 0

sm.sendNext("ฉันมีความลับจะบอก... แต่ต้องทายตัวเลขให้ถูกก่อน")

// while loop: ทำซ้ำตราบใดที่ทายผิด
while (guess != secretNumber) {
    guess = sm.sendAskNumber("ทายเลขมาสิ (1-100)", 1, 1, 100)
    
    if (guess < secretNumber) {
        sm.sendSayOkay("น้อยไปนะพวก!")
    } else if (guess > secretNumber) {
        sm.sendSayOkay("เยอะไปแล้ว!")
    }
}

sm.sendSayOkay("ถูกต้องนะคร้าบบบ! เลขที่ออกคือ 42")
```
