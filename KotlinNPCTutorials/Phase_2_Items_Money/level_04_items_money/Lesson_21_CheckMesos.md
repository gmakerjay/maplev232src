# 🎓 Level 21: เศรษฐีมีตังค์ (Checking Mesos)

ยินดีต้อนรับสู่ Phase 2! เฟสนี้เราจะมายุ่งกับ "กระเป๋าตังค์" และ "ช่องเก็บของ" ของผู้เล่นกัน
เริ่มจากสิ่งที่สำคัญที่สุดในโลกทุนนิยม... **เงิน (Mesos)**

## 📜 ภารกิจที่ 24: นายมีตังค์เท่าไหร่?
คำสั่ง: `chr.getMesos()` (คืนค่าเป็น Long เพราะเงินในเกมเก็บได้เกิน 2 พันล้าน)

### **Code ตัวอย่าง (CheckMoney.kts)**
```kotlin
val money = chr.getMesos() // ดึงเงินปัจจุบัน

sm.sendNext("นายมีเงินติดตัวอยู่ $money Mesos")

if (money < 50) { // เปรียบเทียบได้เลย (Kotlin ฉลาดพอที่จะเทียบ Long กับ Int)
    sm.sendSayOkay("จนจัง... ไปตีหอยทากเก็บเงินไป๊!")
} else if (money >= 1_000_000) { // ใช้ _ คั่นตัวเลขได้นะ (Readable Format)
    sm.sendSayOkay("โห! ป๋ามากครับพี่")
}
```

---

## 🧐 **Long vs Int**
*   **Int**: เก็บได้ max ประมาณ 2,147 ล้าน
*   **Long**: เก็บได้โคตรเยอะ (9 ล้านล้านล้าน)
*   ใน SwordieMS เงินเก็บเป็น `Long` ดังนั้นเวลาประกาศตัวแปรค่าคงที่ ถ้าเลขเยอะๆ ให้เติม `L` ข้างหลัง เช่น `10000000000L`

```kotlin
val rich = 9_999_999_999L
if (chr.getMesos() > rich) {
    sm.sendSay("ท่านเทพเจ้าแห่งเงินตรา!")
}
```
